# Dan's Plugins Manager

**Your purchased Obsidian plugins, all in one place.**

Dan's Plugins Manager is the companion plugin for [Dan's Plugins](https://plugins.danharebin.com). Sign in with your store account to access and manage the Obsidian plugins you've purchased.

**[Explore plugins](https://plugins.danharebin.com)** · **[Account & store](https://plugins.danharebin.com/store)** · **[Installation guide](docs/INSTALLATION.md)** · **[Latest release](https://github.com/danharebin/dans-plugins-releases/releases/latest)**

---

## What it does

- **One hub:** View the plugins available to your account in Obsidian.
- **Install directly:** Download and install authorized plugins without manually handling paid release packages.
- **Updates in one place:** Check installed and available versions, then install verified updates.
- **You're in control:** Automatic installation is optional and off by default; manual update checks remain available.
- **Use it across devices:** Manager v1.1.0 is designed for Windows, macOS, Android, and iOS/iPadOS. Linux support has not been verified on a physical device.

Purchases happen on the **[Dan's Plugins store](https://plugins.danharebin.com/store)**, not inside the manager.

## Install with BRAT

1. Open **Obsidian → Settings → Community plugins** and enable community plugins if prompted.
2. Select **Browse**, search for **BRAT**, then install and enable it.
3. Open **BRAT settings → Beta plugin list → Add beta plugin**.
4. Paste the repository URL below and select **Add plugin**.
5. Enable **Dan's Plugins** under Community plugins.

```text
https://github.com/danharebin/dans-plugins-releases
```

[Read the step-by-step installation guide](docs/INSTALLATION.md), including opening the manager on desktop and mobile.

## Open your plugin hub

1. Open Obsidian's **Command palette** (`Ctrl + P` on Windows/Linux, `Cmd + P` on macOS; use the command palette on mobile).
2. Search **Dan's Plugins: Open hub** and select it.
3. Sign in using the account you use on the store.
4. Choose **Install** or **Update** for the plugins available to you.

## Updates and account access

The v1.1.0 manager checks for available updates on a **24-hour cadence**, with a manual check available at any time. **Automatic installation is off by default.** When supported by your Obsidian version and device, the manager can remember your sign-in for up to **30 days** without saving your password.

Some updates require Obsidian to stop the running plugin or restart before the new version becomes active. Your plugin settings and vault data are intended to remain intact.
