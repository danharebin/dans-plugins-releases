# Dan's Plugins

## Repository roles

**This repository is still required.** It publicly distributes the compiled **Dan's Plugins Manager**, which BRAT installs and updates from GitHub Releases. The private `danharebin/dans-plugins` source repository publishes the Manager here using its existing manual release workflow.

The website, Stripe and Supabase backend live in `danharebin/dans-plugins-platform`. **Paid plugin ZIPs do not belong in this repository**; they are delivered from private Supabase Storage after authorization. Do not put source code, customer information or private keys here.


The official distribution repository for Dan's Plugins Manager for Obsidian.

The manager lets customers sign in and securely install and update their purchased plugins.

## Installation

Install the manager using the Obsidian BRAT community plugin.

GitHub releases contain the verified manager files: `main.js`, `manifest.json`, and `styles.css`.
